# COVID Vaccine Tracker

An interactive dashboard visualizing live CDC data on COVID-19 vaccination rates, case counts, and brand-specific vaccine information across all 50 US states.

## What it does
- Dynamic map rendering that updates displayed metrics in real time as new CDC data becomes available
- State-by-state breakdown of vaccination rates, case counts, and vaccine brand information

## Tech Stack
Java

## Background
Built as a high school capstone project.
